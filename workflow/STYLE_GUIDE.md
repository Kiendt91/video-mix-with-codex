# Style Guide

## Default Look

Use a cinematic, high-contrast treatment:

- dark vignette
- subtle warm/cool color grade
- thin progress/meter line
- minimal title text
- short flash on cuts
- radial pulse on major impacts

## Transition Policy

Default transitions:

- hard cut on beat
- 2-5 frame flash
- subtle impact pulse
- momentary grade shift

Avoid by default:

- curtain wipe
- left/right slide reveal
- thick masks crossing the screen
- repeated generic zoom transitions
- heavy blur that hides the cut

## Shot Variety

A short 20-30 second test should usually use 7-10 unique shots. A full 55-60 second version should use enough unique material to avoid visible recycling.

If a source clip must be reused, return to it with a clear purpose: logo callback, chorus reprise, or final resolve.
